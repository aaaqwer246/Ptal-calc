# 公共交通可达性计算器

根据附近公交、地铁的实际步行距离和发车频率，估算一个地点的公共交通可达性（PTAL），并展示各条线路的计算明细。支持地图选点、手动录入、参数调整和方案导入导出。

## 开始使用

| 使用方式 | 操作 |
| --- | --- |
| 在线使用 | 打开已部署的网站，输入地名、入口名称或高德坐标 |
| 本地使用 | 安装 Python 3 后，双击 `启动本地计算器.cmd`，浏览器会打开 `http://127.0.0.1:8765/`；使用期间保持启动窗口打开 |
| 仅手动计算 | 直接打开 `index.html`，录入线路、步行距离和班次，无需联网查询 |

1. 搜索并选择地点后开始分析；也可点击 **启用高德地图**，在地图选点后点击 **搜索分析**。
2. 程序检索附近公交、地铁站点，并规划实际步行路线。同一模式的同一线路，只计入步行最近的有效站点。
3. 在明细表中校核目标时段的单向发车频率、步行距离及线路状态。默认班次仅用于估算，不能当作实际运营数据。
4. 修改参数或班次后，本地立即重算。可保存 JSON 方案、导入复算，或导出明细 CSV。

查询期间可以取消。查看已取得的路径、修改班次或重新计算，不会新增地点和路线查询。

## 个人设置

| 网页中的设置 | 地图与查询使用的服务 |
| --- | --- |
| 填写个人高德 Key 和配套安全密钥 | 全部优先使用个人配置 |
| 两项清空后保存 | 使用默认服务 |

个人 Key 请选择高德 **Web端（JS API）** 类型，不能填写 Web 服务 Key。两项需要同时填写或同时清空；个人配置无效或额度不足时，会提示错误，不自动改用默认服务。

配置保存在当前浏览器，正常关闭网页、重启浏览器后仍保留。不同浏览器、不同网址的配置彼此独立；无痕模式或清除浏览器数据后无法保留。个人配置不会上传到默认服务，也不会写入导出的方案。

默认服务需要由部署者配置，并受高德权限、配额和站点使用限额约束。地图 Key 在浏览器中可见，应在高德控制台限制允许使用的域名。

## 计算口径

默认步行速度为 **80 米/分钟**，公交步行上限为 **640 米**，地铁为 **960 米**；默认公交 **4 辆/小时**、地铁 **12 列/小时**，均可修改。

计算依次使用发车频率、步行时间和可靠性修正：

```text
SWT = 30 / 每小时班次
AWT = SWT + 可靠性修正
TAT = 步行距离 / 步行速度 + AWT
EDF = 30 / TAT
```

可靠性修正默认为公交 2 分钟、地铁 0.75 分钟。每种模式中，最高 EDF 的线路权重为 1，其余为 0.5；加权求和得到可达性指数 AI，再换算为 PTAL 等级。

计算参考 [TfL Connectivity Assessment Guide](https://content.tfl.gov.uk/connectivity-assessment-guide.pdf)。本工具是公交与地铁可达性的辅助分析工具，不是官方认证评价结果。

## 数据边界

- 地图不提供本工具所需的实际发车频率，应按统一目标时段人工校核。
- 地铁站点坐标不一定是可进入的出入口，进站、安检和站内步行需另行核实。
- 路线查询失败时保留未知距离，不用直线距离或零距离替代；检索不完整会提示。
- 当前页面会复用已取得的查询结果，刷新页面后不保留接口缓存。需要更新时可选择 **重新查询站点和路线**。
- 本机查询统计不是高德账单，也不包含所有地图加载和内部请求。分享或再利用导出方案中的地图数据，仍须遵守高德的数据授权要求。
