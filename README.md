# 公共交通可达性计算器

微信公众号：Guillaume的工作间

打开 `index.html` 即可手工分析，也可直接输入关键词自动联想具体门或出入口；需要图上选点时再点击 **启用高德地图**。无需构建，不依赖外部字体。

## 使用

1. 直接输入地名、具体门或出入口名称，停顿400毫秒后自动更新高德地点候选，选中后分析；也可启用地图点击选点后按 **搜索分析**。支持高德 GCJ-02 坐标（经度,纬度），以及↑↓选择、Enter确认和Escape收起候选。
2. 程序分别完整分页检索公交与地铁候选站点，对全部有效接入点经 Worker 调用高德 Web 服务步行接口。按实际路线长度筛选并合并同线最近站点。
3. 在明细表校核统一目标时段的单向班次。默认公交4辆/小时、地铁12列/小时是**假设**，不是实时运营数据。
4. 参数、距离、频率及启用状态修改后本地重算。可保存 JSON 方案、导入复算、导出带计算过程及完整性说明的 CSV。

## 请求与配额

GitHub Pages 提供静态页面，Cloudflare Worker 调用高德 Web 服务。JS API 仅用于按需加载地图；联想、地点详情、搜索、站点周边及步行查询均经 Worker。JS Key 与 jscode 仍由地图设置填写，属于浏览器端配置，不能与服务器 Web 服务 Key 混用。

- 400毫秒联想防抖、输入法组词保护、旧响应丢弃、取消队列及网络请求；同坐标接入点共享步行距离。
- 仅在当前页面内存复用结果，最多300项；刷新失效，启动时删除旧版持久化接口缓存。Worker 不缓存高德数据，响应禁用 HTTP 缓存。方案导出是用户主动操作，分享及再利用仍需遵守数据授权。
- 公交及地铁分别完整分页，Web 服务每页25项，保留分页重复和上限警告；全部有效接入点规划实际步行路线。修改班次、参数及查看已取得的路线不发起业务查询。
- 步行最多2个在途请求，启动间隔600毫秒；失败不自动重试，避免超时后重复扣额。强制刷新越过页面内存复用。
- 单 IP 每60秒120次（Cloudflare 边缘近似限流），全站每分钟120次、北京时间每日1000次为默认保护预算，可在 Worker 配置调整。全站计数由单个 Durable Object 原子控制，已发出的失败请求也计数。
- 高德日配额错误触发当日熔断；429或服务配置异常会停止当前操作的后续网络请求，不以直线距离填补未知路线。次日重新尝试不保证高德额度已恢复。
- 本机计数仅为业务请求尝试次数，含失败与取消，不代表高德计费；地图加载及 SDK 内部请求另计。Worker 不会增加高德配额，也不轮换 Key。

部署步骤见 [DEPLOY.md](DEPLOY.md)。

## 计算口径与边界

- 步行速度80米/分钟，公交上限640米，地铁上限960米；公交可靠性修正2分钟，地铁0.75分钟。
- SWT=30/班次；AWT=SWT+可靠性修正；TAT=距离/速度+AWT；EDF=30/TAT。每种模式最大EDF取权重1，其余0.5。
- 分级采用连续上限：0、2.5、5、10、15、20、25、40、40以上，使用完整精度判断。两位小数显示值靠近阈值时可能相同，等级仍按原始值判断。
- 路线失败不回退直线距离，不作为0米处理；没有有效数据时显示「—」，避免误报0级。超出步行上限、重复接入、0班次、停运/在建均注明排除原因。
- 高德 POI 的线路名称依赖站点地址字段，未知信息不伪造；地铁POI未必位于实际可进入的出入口，进站、安检、站内距离及数据更新需核实。接口失败或外部接口分页上限会明确提示，不能把不完整结果当成完整评价。
- 当前页面复用结果不能替代实地校核；道路封闭或站点调整后应勾选强制刷新。

依据：[TfL Connectivity Assessment Guide §2.5](https://content.tfl.gov.uk/connectivity-assessment-guide.pdf)、[高德 PlaceSearch](https://lbs.amap.com/api/maps-javascript-api/reference/search/placesearch)、[高德步行规划](https://lbs.amap.com/api/javascript-api/reference/route-search)。本项目支持公交及地铁两种模式，不是官方认证评价工具。

## 文件与验证

- `index.html`、`styles.css`、`src/`：静态前端，无需构建。
- `src/deployment.js`：公开 Worker 地址，不能填写任何 Web 服务密钥。
- `worker/index.mjs`、`worker/wrangler.toml`：后端与绑定配置。
- `tests/`：计算模型、适配器及 Worker 模拟集成测试。

运行 `node --test tests/*.test.cjs`；测试使用模拟响应，不消耗高德配额，不能代替上线后的真实联调。
